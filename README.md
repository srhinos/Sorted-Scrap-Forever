# Sorted - Scrap for WoW Forever

The Scrap plugin for Sorted (by Daft Vader), packaged for WoW: Forever so WowUp installs it. Pairs with [srhinos/Sorted-Forever](https://github.com/srhinos/Sorted-Forever).

The first commit imports v1.1.1 exactly as published on [CurseForge](https://www.curseforge.com/wow/addons/sorted-scrap); later commits are Forever fixes.
